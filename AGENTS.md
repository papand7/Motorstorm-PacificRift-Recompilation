# MotorStorm: Pacific Rift native recompilation

- Use ahead-of-time ps3recomp translation for original PPU/SPU code. Do not replace gameplay with an interpreter, engine remake, or approximate physics.
- Preserve the supplied ISO and extracted `EBOOT.BIN`. Keep extracted inputs in `original/`, decrypted ELFs in `generated/decrypted/`, analysis and generated code in `generated/`, and compiled output in `build/`.
- Pin ps3recomp to `0fe7dbf5db9a467aca268865fb26170ea113c541`, the revision of the supplied v0.15.0 package, until a deliberate upgrade is tested.
- `EBOOT.BIN` is a retail SELF. Its visible ELF header is insufficient evidence that executable sections are decrypted. Require a verified standalone ELF before function discovery or code generation.
- Record commands, hashes, logs, and milestone-specific results. Label findings VERIFIED, PARTIAL, HYPOTHESIS, or BLOCKED. Do not infer gameplay or compatibility from generated files alone.
- Use the framework's project template and runtime; keep game-specific changes outside `ps3recomp/` where practical. Add focused tests when changing framework behavior.
- No P3/P4 work until original startup code runs. Consult `docs/STATUS.md`, `docs/RESEARCH.md`, and `docs/BUILD.md` before continuing.
- Public source must exclude all game/firmware inputs, decrypted modules, assets, lifted PPU/SPU source, objects, and linked game binaries. Keep `libsre.sprx` and any lifted firmware output private; implement public compatibility APIs independently.
- Run `python tools/audit_public.py --staged` before commits and `python tools/audit_public.py --tree <release-staging>` before release. Never upload private inputs or generated output to public CI or external services. See `docs/DISTRIBUTION.md` and `THIRD_PARTY_LICENSES.md`.
