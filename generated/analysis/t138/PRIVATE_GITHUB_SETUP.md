## 7. Recommended repository settings

1. Visibility **private**; create a *new* repository — do **not** use GitHub "Fork" of `sp00nznet/ps3recomp`
   (a fork of a public repository cannot be private).
2. Default branch `main`, protected: pull requests required, no force pushes, no deletion, status check `ci`.
3. Automatic head-branch deletion: off.
4. Secret scanning + push protection, Dependabot security updates: on where the plan allows.
5. Actions: allow only selected actions (`actions/*`), default workflow token read-only, no repository secrets.
6. ps3recomp: host the MotorStorm branches in a **second private repository** (e.g. `motorstorm-ps3recomp`) and
   link it as a submodule later, or keep it local; it is not part of this repository's history.
7. In `ps3recomp`, protect against an accidental public push:
   `git -C ps3recomp remote set-url --push origin DISABLED` (fetch keeps working for all worktrees). **Applied 2026-10-28 at the owner's request**; previously withheld because
   it changes configuration shared by other agents' worktrees.
