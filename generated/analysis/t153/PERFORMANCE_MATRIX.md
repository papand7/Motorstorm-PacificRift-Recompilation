**Omitted combinations and why:**
- T150 alone on T146 defaults (without the epoch): T150's A/B (C arm) covers it; in the preset the epoch is always on.
- Fast fetch without compact: T151 measured no gain with fat records (write-bound), so it is not worth a launch.
- Kick and fast fetch separately: T151's own A/B (Q1/Q2) isolates them. Split C only if C differs from P.
